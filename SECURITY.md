# Security policy

## Supported version

Security fixes принимаются для текущей ветки `main`.

## Reporting

Не публикуйте уязвимость в issue вместе с ключами, кампанией или приватными
данными. Свяжитесь с владельцем репозитория приватным каналом и приложите:

- версию/commit;
- минимальные шаги воспроизведения;
- влияние;
- безопасный proof of concept без пользовательских данных.

## Scope

AI-DND v1 предназначен для localhost или доверенной LAN. Он не рассчитан на
прямое размещение в интернете. Секреты должны передаваться только через
environment variables; prompts и runtime DB нельзя прикладывать к отчёту.
