# ADR 0004: Изоляция voice-модулей

- Статус: принято
- Дата: 2026-07-29

## Решение

STT/TTS являются опциональными provider interfaces. Тяжёлый локальный TTS не
входит в core lock и должен запускаться отдельным worker-процессом.

## Почему

ML-зависимости, CUDA и platform-specific wheels не должны ломать установку
игрового ядра. Недоступный worker переводит job в degraded state, сохраняя
текстовый результат.
