# ADR 0002: WebSocket и durable replay

- Статус: принято
- Дата: 2026-07-29

## Решение

Использовать один WebSocket transport с отдельной очередью на клиента и
сохранять события с campaign sequence в SQLite.

## Почему

Redis `BLPOP` распределяет сообщения между потребителями и не является
broadcast. Durable sequence даёт одинаковый порядок всем зрителям и
восстановление после reconnect без обязательной внешней инфраструктуры.
