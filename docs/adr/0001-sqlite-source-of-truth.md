# ADR 0001: SQLite как source of truth

- Статус: принято
- Дата: 2026-07-29

## Решение

Использовать SQLite через SQLAlchemy 2 и Alembic. JSON оставить только для
импорта и экспорта.

## Почему

Целевая v1 локальна и обслуживается одним процессом. SQLite даёт транзакции,
ограничения, блокировки и переносимость без отдельного сервера. Repository/use
case границы позволяют позднее заменить адаптер на PostgreSQL.

## Последствия

Включаются foreign keys, WAL и `busy_timeout`; запись выполняется в явных
транзакциях. Для LAN-инсталляции нельзя размещать файл БД на сетевом диске.
