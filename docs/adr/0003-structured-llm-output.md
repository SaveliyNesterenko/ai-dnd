# ADR 0003: Структурированные LLM-ответы

- Статус: принято
- Дата: 2026-07-29

## Решение

Player turn и Observer output валидируются Pydantic-схемами. Если модель
поддерживает `json_schema`, adapter использует его; иначе применяется JSON mode
и та же локальная валидация.

## Последствия

Observer не выдаёт произвольный JSON Patch. Разрешены только доменные команды
ресурсов, attributes, inventory и status effects. Невалидный результат не
изменяет кампанию.
