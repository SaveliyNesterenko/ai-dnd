# Публичные пакеты кампаний

Пакеты используют формат `ai-dnd-campaign-pack/v1` и импортируются в GM Console через
**Кампания → Импортировать ZIP**. Пакет представляет собой ZIP с файлами `manifest.json`,
`README.md`, `LICENSES.md`, `ASSET_GUIDE.md` и всеми указанными в манифесте файлами из `assets/`.

В манифесте для каждого ассета указываются путь, SHA-256, тип медиа и лицензия. Перед активацией
кампании импорт проверяет архив целиком. API-ключи и сгенерированная речь в пакет не входят.
Голосовые образцы становятся доступны после установки дополнения командой
`uv sync --locked --extra voice`.

Для ZIP кампании действует отдельный лимит 64 МиБ (`AI_DND_MAX_CAMPAIGN_PACK_BYTES`). Его изменение
не увеличивает лимит 20 МиБ для голосовых загрузок (`AI_DND_MAX_UPLOAD_BYTES`).

Подготовьте закрытую исходную папку по образцу `demo/trial-campaign-template`, добавьте в неё
ассеты с подтверждёнными правами и соберите файл для релиза:

```powershell
uv run python scripts/build_campaign_pack.py C:\private\trial-campaign .\dist\ai-dnd-trial-campaign-v1.zip
```

Опубликуйте ZIP и файл `.sha256` в соответствующем GitHub Release. Исходную папку и бинарные
медиа не добавляйте в Git-репозиторий.
