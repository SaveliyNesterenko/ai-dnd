# Пробная кампания «Тени Руин Астралии»

Кампания рассчитана на 30–45 минут. Силия и Каэль Роан начинают путь на перекрёстке возле руин
Астралии, встречают травницу Элару и старика Сайласа, а затем сталкиваются с Горгаром и его
гоблином-разведчиком. Подробный ход кампании приведён в `GM_GUIDE.md`.

## Запуск

1. Откройте GM Console через ссылку, которую выводит команда `ai-dnd serve --open`.
2. В меню «Кампания» нажмите «Импортировать ZIP» и выберите этот архив.
3. Откройте настройки сцены, проверьте стартовую локацию и музыку.
4. Добавьте нужных NPC или врагов на сцену и запустите игровое событие.
5. Передайте зрителям локальный адрес spectator-экрана и код из верхнего меню GM Console.

Кампания работает без API-ключа: ходы можно вводить вручную. API-ключ включает AI-функции.
Для озвучки установите голосовое дополнение командой `uv sync --locked --extra voice`, после чего
запускайте сервер с `uv run --no-sync ai-dnd serve --open`.
