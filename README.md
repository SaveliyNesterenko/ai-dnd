# Движок для текстовых ролевых игр на базе ИИ

Этот проект представляет собой движок для текстовых ролевых игр, в котором ответы персонажей генерируются большой языковой моделью. Он использует бэкенд на FastAPI для управления состоянием игры и взаимодействия с ИИ, а также простой HTML-фронтенд в качестве консоли Мастера игры (GM).

## Компоненты

- **`orchestrator.py` (Бэкенд):** Основной сервер, созданный на FastAPI. Он обрабатывает основную игровую логику, включая:
    - Загрузку данных персонажей и истории событий.
    - Форматирование контекста и промпта для ИИ-модели.
    - Взаимодействие с API ИИ.
    - Управление журналом событий игры.

- **`frontend/gm-console/index.html` (Фронтенд):** Одностраничный веб-интерфейс, который служит консолью Мастера игры. Он позволяет пользователю:
    - Выбрать персонажа.
    - Ввести ситуацию или промпт для реакции персонажа.
    - Просмотреть сгенерированный ИИ ответ (мысли и действия).

- **`data/` (Файлы данных):**
    - `characters.json`: JSON-файл, содержащий подробную информацию о доступных персонажах (например, биография, личность, воспоминания).
    - `event_log.json`: JSON-файл, в котором хранится история всех произошедших событий и действий, обеспечивая долгосрочный контекст для ИИ.

## Как это работает

1.  Пользователь открывает `frontend/gm-console/index.html` в веб-браузере.
2.  Пользователь выбирает персонажа и вводит промпт.
3.  Фронтенд отправляет ID персонажа и промпт пользователя на эндпоинт `/generate` на бэкенд-сервере.
4.  Бэкенд загружает соответствующие данные персонажа и полную историю событий.
5.  Он формирует подробный промпт для ИИ, включающий биографию персонажа, его состояние, память, историю игры и текущую ситуацию.
6.  Бэкенд отправляет этот полный промпт в API ИИ.
7.  ИИ отвечает, разделяя ответ на внутренние мысли персонажа и его внешние действия/речь.
8.  Бэкенд обновляет `event_log.json` новым событием и отправляет ответ ИИ обратно на фронтенд для отображения.

## Как запустить

### 1. Предварительные требования

Вам понадобится установленный Python 3, а также библиотеки, перечисленные в `requirements.txt`.

### 2. Переменные окружения

Создайте файл с именем `.env` в корне проекта. Этот файл будет содержать ваш секретный API-ключ. Добавьте в него следующую строку:

```
OPENAI_API_KEY="ваш_api_ключ"
```

При желании вы можете указать другой эндпоинт API:

```
OPENAI_BASE_URL="https://ваш_api_эндпоинт/v1"
```

### 3. Запустите бэкенд-сервер

Выполните следующую команду в вашем терминале:

```bash
uvicorn orchestrator:app --reload
```

### 4. Запуск фронтенда

cd frontend/gm-console
python -m http.server 8080
http://localhost:8080/console-gm.html


### 5. Запуск чере start.py 
python start.py
