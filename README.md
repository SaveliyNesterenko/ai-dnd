# Движок для текстовых ролевых игр на базе ИИ

Этот проект представляет собой движок для текстовых ролевых игр, в котором ответы персонажей генерируются большой языковой моделью. Он использует бэкенд на FastAPI для управления состоянием игры, а также два фронтенд-приложения: интерактивную консоль Мастера игры (GM) и **зрительский экран (Spectator View)**, который в реальном времени отображает изменения в игре.

Обновления между сервером и клиентами передаются в реальном времени с помощью технологии **Server-Sent Events (SSE)**.

## Компоненты

-   **`start_dev.py` (Скрипт запуска):** Утилита для удобного запуска и управления сервером и всеми компонентами проекта.
-   **`orchestrator.py` (Бэкенд):** Основной сервер на FastAPI. Он обрабатывает основную игровую логику, включая:
    -   Загрузку и предоставление данных об игре (персонажи, локации, события).
    -   Форматирование промптов для ИИ-модели.
    -   Взаимодействие с API ИИ.
    -   Предоставление обновлений в реальном времени через Server-Sent Events (SSE).
-   **`response_handler.py` (Обработчик ответов):** Модуль для обработки и структурирования ответа от языковой модели.
-   **`frontend/gm-console/` (GM-консоль):** Основной интерфейс Мастера игры для управления персонажами, локациями и ходом событий.
-   **`frontend/spectator/` (Зрительский экран):** Отдельный интерфейс, который отображает текущую игровую локацию. Идеально подходит для вывода на второй монитор или трансляции для наблюдателей.
-   **`data/` (Файлы данных):** JSON-файлы, хранящие состояние игры.

## Быстрый запуск

### 1. Установка зависимостей

Для работы проекта требуется Python 3. Установите все необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 2. Настройка API-ключа

Создайте файл `.env` в корневой папке проекта и добавьте в него ваш API-ключ для доступа к языковой модели:

```
OPENAI_API_KEY="ВАШ_КЛЮЧ"
# OPENAI_BASE_URL="АДРЕС_СЕРВЕРА_API" # Опционально
```

### 3. Запуск

Для запуска сервера и фронтенда используйте скрипт `start_dev.py`:

```bash
python start_dev.py
```

Этот скрипт автоматически откроет консоль Мастера игры и зрительский экран в вашем браузере.
