# Движок для текстовых ролевых игр на базе ИИ

Этот проект представляет собой движок для текстовых ролевых игр, в котором ответы персонажей генерируются большой языковой моделью. Он использует бэкенд на FastAPI для управления состоянием игры, а также два фронтенд-приложения: интерактивную консоль Мастера игры (GM) и **зрительский экран (Spectator View)**, который в реальном времени отображает изменения в игре и **озвучивает реплики персонажей с помощью локальной нейросети (XTTS v2)**.

Обновления между сервером и клиентами передаются в реальном времени с помощью технологии **Server-Sent Events (SSE)**.

## Компоненты

-   **`start_dev.py` (Скрипт запуска):** Утилита для удобного запуска и управления сервером и всеми компонентами проекта в режиме разработки.
-   **`orchestrator.py` (Бэкенд):** Основной сервер на FastAPI. Он обрабатывает основную игровую логику, включая:
    -   Загрузку и предоставление данных об игре (персонажи, локации, события).
    -   Форматирование промптов для ИИ-модели.
    -   Взаимодействие с API ИИ.
    -   Вызов сервиса озвучивания.
    -   Предоставление обновлений в реальном времени через Server-Sent Events (SSE).
-   **`response_handler.py` (Обработчик ответов):** Модуль для обработки и структурирования ответа от языковой модели.
-   **`tts_service.py` (Сервис озвучивания):** Отвечает за генерацию речи из текста с помощью локальной модели **Coqui XTTS v2**, используя CUDA для ускорения на видеокартах NVIDIA.
-   **`frontend/gm-console/` (GM-консоль):** Основной интерфейс Мастера игры для управления персонажами, локациями и ходом событий.
-   **`frontend/spectator/` (Зрительский экран):** Отдельный интерфейс, который отображает игровую сцену. В реальном времени показывает анимированные реплики персонажей и проигрывает сгенерированную озвучку.
-   **`data/` (Файлы данных):** JSON-файлы, хранящие состояние игры.
-   **`assets/` (Ресурсы):** Статические файлы, включая изображения персонажей, образцы голосов для клонирования и сгенерированные аудиофайлы.

## Требования

### 1. Основные зависимости

Для работы проекта требуется Python 3.9+. Все необходимые Python-библиотеки перечислены в `requirements.txt`.

### 2. Требования для локального Text-to-Speech (Озвучивания)

Функция озвучивания работает локально на вашем компьютере и для высокой производительности требует **видеокарту NVIDIA с поддержкой CUDA**.

-   **NVIDIA CUDA Toolkit:** Необходим для того, чтобы Python-библиотеки могли использовать вашу видеокарту.
-   **PyTorch с поддержкой CUDA:** Проект использует библиотеку PyTorch для работы нейросети. Убедитесь, что у вас установлена версия с поддержкой CUDA.
-   **Coqui TTS:** Модель для генерации речи. Устанавливается автоматически вместе с другими зависимостями из `requirements.txt`. При первом запуске модель (несколько гигабайт) будет автоматически скачана в ваш локальный кэш.

## Быстрый запуск

2.  **Запустите скрипт разработки:**
    Этот скрипт автоматически создаст виртуальное окружение, установит все зависимости и запустит сервер.
    ```bash
    python start_dev.py
    ```

3.  **Откройте интерфейсы в браузере:**
    Скрипт автоматически откроет **GM-консоль** и **Зрительский экран**. Если этого не произошло, откройте их вручную по адресам, указанным в терминале (обычно `http://127.0.0.1:8000`).
