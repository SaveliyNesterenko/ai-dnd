# Движок для текстовых ролевых игр на базе ИИ

Этот проект представляет собой движок для текстовых ролевых игр, в котором ответы персонажей генерируются большой языковой моделью. Он использует бэкенд на FastAPI для управления состоянием игры и взаимодействия с ИИ, а также простой HTML-фронтенд в качестве консоли Мастера игры (GM).

## Компоненты

-   **`orchestrator.py` (Бэкенд):** Основной сервер, созданный на FastAPI. Он обрабатывает основную игровую логику, включая:
    -   Загрузку данных персонажей и истории событий.
    -   Форматирование контекста и промпта для ИИ-модели.
    -   Взаимодействие с API ИИ.
    -   Вызов `response_handler.py` для обработки и сохранения ответа.
-   **`response_handler.py` (Обработчик ответов):** Этот модуль отвечает за обработку и структурирование ответа, полученного от языковой модели.
-   **`frontend/gm-console/` (Фронтенд):** Одностраничный веб-интерфейс, который служит консолью Мастера игры.
-   **`data/` (Файлы данных):**
    -   `characters.json`: JSON-файл, содержащий подробную информацию о доступных персонажах.
    -   `npc.json`: JSON-файл, содержащий информацию о неигровых персонажах.
    -   `event_log.json`: JSON-файл, в котором хранится история всех произошедших событий и действий.

## Быстрый запуск

### 1. Установка зависимостей

Для работы проекта требуется Python 3. Установите все необходимые библиотеки с помощью `pip`:

```bash
pip install -r requirements.txt
```

### 2. Настройка API-ключа

Создайте файл `.env` в корневой папке проекта и добавьте в него ваш API-ключ для доступа к языковой модели:

```
OPENAI_API_KEY="ваш_api_ключ"
```

При необходимости вы можете указать другой эндпоинт API:

```
OPENAI_BASE_URL="https://ваш_api_эндпоинт/v1"
```

### 3. Запуск

Запустите проект с помощью одного из скриптов:

-   **Для обычного использования:**

    ```bash
    python start.py
    ```

-   **Для разработки (сервер будет автоматически перезагружаться при изменениях в коде):**

    ```bash
    python start_dev.py
    ```

После запуска в вашем браузере автоматически откроется консоль Мастера игры.
